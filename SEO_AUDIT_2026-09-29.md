# BC Vote Watch SEO audit — September 29, 2026

## Search Console evidence

Property: `sc-domain:bcvotewatch.ca`, Web search, data available through September 27. This is a new site with only eight days of reported data, so short term changes should not be treated as a durable trend.

The drop begins before the September 25 removal of Chinese pages. That removal can reduce future Chinese query coverage, but it does not explain the initial decline. Search Console's page report shows only a handful of clicks to Chinese URLs over the available period. The cancelled Abbotsford-Mission by-election page had zero clicks, so it is not the main source of the measured drop either. Most clicks are spread across 2024 result and riding pages; the site has no single high-volume landing page to blame.

The largest measured change is fewer impressions (626 on Sep 22 versus 360 on Sep 27), alongside a smaller CTR decline. This fits a new site's initial search visibility settling after a news event, but Search Console does not establish the cause. The average position across the reported period is 6.8; a page or query level before/after comparison will be needed once more data accrues.

## Technical checks and fixes

- Search Console reported the submitted sitemap as **Success**, last read September 29, with 109 discovered URLs. The local sitemap has 109 URLs.
- `robots.txt` permits crawling. Public sample pages return HTTP 200; retired Chinese URLs return 301 to their English counterparts.
- All 109 indexable local HTML pages have one self-referencing canonical, one description, one H1 and unique titles. Internal links resolve locally.
- The index coverage report was last updated September 20, before the Chinese page removal. Its 283 indexed / 36 non-indexed figures cannot diagnose the current state.
- Updated the latest professional poll from Liaison's September 29 primary release across the homepage, election guide and polls page; updated the official voting guide and election-status check date.
- Sitemap `lastmod` now advances only for pages reviewed in this change. It no longer labels all 109 pages as updated on every refresh.

## Follow-up measurement

After publication and at least several more days of Search Console data, compare Sep 22–24 with Sep 26 onward by page and query. Watch impressions, CTR and position separately. Check whether the now-retired Chinese URLs lose residual search clicks and whether current 2026 election pages gain impressions after recrawling. Do not assume a code fix can restore event-driven search demand.
